# v0.8.3: No phantom clicks in new menus

A small fix for games built on the engine.

## Fixed
- **A new `Gui` clicked whatever was under the pointer in its first frame.**
  - **Symptom:** opening a menu could change a setting by itself: a button fired, a checkbox flipped or a slider jumped, depending on what was under the pointer when the menu opened. It happened when the mouse had been clicked earlier, for example to shoot in the game or to open the menu.
  - **Cause:** a `Gui` sees clicks by comparing the mouse's press and release counts with the ones it saw last frame. A new `Gui` started counting from zero, so every earlier click counted as a click in its first frame.
  - **Fix:** a new `Gui` starts from the counts as they are when it is made, so only clicks made after that count.

## Use it

```xml
<dependency>
  <groupId>io.github.ad0bert</groupId>
  <artifactId>engine-named-scratch</artifactId>
  <version>0.8.3</version>
</dependency>
```

Nothing else changed from v0.8.2, so upgrading is just the version number.
