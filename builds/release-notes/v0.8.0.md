# v0.8.0: Engine as a library, game states and packaged builds

The first release of the engine as a library: build a game in its own project, depend on the engine, and ship it with its own Java runtime. It also adds what a game needs beyond a single scene: screens and levels, pause, window options, mod folders and saved settings.

## Use it in your game

The engine is published to GitHub Packages:

```xml
<repositories>
  <repository>
    <id>github</id>
    <url>https://maven.pkg.github.com/ad0bert/EngineNamedScratch</url>
  </repository>
</repositories>

<dependencies>
  <dependency>
    <groupId>io.github.ad0bert</groupId>
    <artifactId>engine-named-scratch</artifactId>
    <version>0.8.0</version>
  </dependency>
  <!-- the engine logs through SLF4J only; pick a backend -->
  <dependency>
    <groupId>ch.qos.logback</groupId>
    <artifactId>logback-classic</artifactId>
    <version>1.5.18</version>
    <scope>runtime</scope>
  </dependency>
</dependencies>
```

GitHub Packages needs a login even for public packages. Add a `github` server to `~/.m2/settings.xml` with your user name and a token that has `read:packages`. Requires JDK 25. The OpenGL, sound and gamepad native libraries come with the Maven dependencies.

## New

### Game states and levels
- **State stack:** `engine.states()` holds a stack of `GameState`s, such as a title screen, levels and a pause menu. `push`, `pop`, `replace` and `clear` take effect at the start of the next update step, so a state never ends in the middle of its own update.
- **Update and draw:** the top state gets updates; every state draws, bottom first, so a pause menu covers the level's HUD.
- **Levels:** `LevelState` fills the scene when it starts. When it ends, it clears the scene and frees the meshes, textures and sounds first loaded during the level. Going to the next level is `engine.states().replace(new Level2())`.
- **Without states:** the same building blocks are available directly: `Scene.clear()` and `ResourceManager.openScope()` / `scope.close()`.

### Pause
- `engine.setPaused(true)`, or a top state whose `simulates()` returns false, stops physics, animation and component updates.
- Sound keeps playing so a menu's clicks and music work. Use `engine.audio().mixer().setMuted(true)` to silence it.
- A system can opt out of the pause with `ISystem.runsWhilePaused()`.

### Window
- At run time: `setFullscreen` (borderless on the current monitor), `setVsync`, `setWindowSize`, and `monitorResolutions()` for a settings menu.
- New config keys `app.fullscreen`, `app.vsync` and `app.id`. The system properties `-Dengine.fullscreen` and `-Dengine.vsync` override them.

### Files, mods and settings
- **Asset folders:** `engine.assets().addRoot(dir)` loads assets from folders before the jar, so mods and user content can replace any texture, model, sound or prefab.
- **Per-user folders:** `engine.userDirs()` gives the platform's settings and save folders (`%APPDATA%`, `~/Library/Application Support`, or `~/.config` and `~/.local/share`). `-Dengine.userDir` redirects them.
- **Settings file:** `Settings` reads and writes a file of player settings, and never leaves a half-written file.
- **Version:** `Engine.VERSION` reports the engine's version.

### Packaging
- The demo shows how to package a game:
  - `target/dist/`: a runnable jar with its dependencies in `lib/`.
  - `mvn package -Pjpackage`: the game with its own trimmed Java runtime (about 106 MB), so players don't need Java installed.
- This release includes the demo as a runnable jar, and packaged for Linux, macOS and Windows.

### Demo
- `P` or the gamepad's Start pauses, and `F11` toggles fullscreen.
- The settings panel has fullscreen and vsync switches.
- Volumes, fullscreen and vsync are remembered between runs.

## Changes to know about
- **Coordinates:** the engine is now `io.github.ad0bert:engine-named-scratch` (it was `EngineTest:EngineTest`).
- **Demo-only files:** the engine jar contains only the engine and its shaders. `application.properties` and the sample models, textures and prefabs moved to the demo, so your game ships its own.
- **Logging:** Logback is no longer included; add a logging backend to your game (see above).
- **`EngineConfig`:** gained the `id`, `fullscreen` and `vsync` fields. The old five-argument constructor still works.
- **Internal packages:** `engine.render.gl`, `engine.audio.al` and `engine.input.jinput` are the backends' internals and may change in any release. Everything else is the API.
- **Demo path:** the runnable demo moved to `demo/target/dist/demo.jar`.

## Assets in this release
- `engine-named-scratch-0.8.0.jar`, plus `-sources` and `-javadoc` jars.
- `demo-0.8.0.zip`: the demo as a runnable jar (needs Java 25).
- `EngineNamedScratch-demo-0.8.0-linux-x64.tar.gz`, `-macos-arm64.tar.gz` and `-windows-x64.zip`: the demo with its own Java runtime. The macOS build isn't signed, so macOS warns the first time you open it (right-click → Open).
