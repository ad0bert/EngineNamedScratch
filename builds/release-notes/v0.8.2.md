# v0.8.2: Fullscreen on Windows

A small fix for games built on the engine.

## Fixed
- **Switching to fullscreen during play could fail on Windows.**
  - **Symptom:** `engine.setFullscreen(...)` while the game was running (for example from an options menu, `F11`, or right after start) could throw from the `engine-fullscreen` thread after five seconds: `Waited 5000ms for ... owner <main-Animator#00>`. The window then stayed as it was. It was seen with vsync on an NVIDIA card.
  - **Cause:** the render loop holds the window's lock while it draws a frame and takes it again right after, so the switch could wait for the lock until it timed out.
  - **Fix:** the engine now pauses drawing while it changes the window, for `setFullscreen` and `setWindowSize`. Changes run one at a time, and a change that still fails is logged as a warning instead of throwing.

## Tip
To open a game in the mode the player chose, pass the saved choice in the `EngineConfig` (`withFullscreen`, `withVsync`) rather than switching once the window is up. The window then opens that way, and no switch is needed.

## Use it

```xml
<dependency>
  <groupId>io.github.ad0bert</groupId>
  <artifactId>engine-named-scratch</artifactId>
  <version>0.8.2</version>
</dependency>
```

Nothing else changed from v0.8.1, so upgrading is just the version number.
