# v0.8.1: Hide the debug text

A small update for games built on the engine.

## New
- **Debug text off at start:** games for players can now hide the engine's debug text (FPS, draw statistics; `F3` still toggles it):
  - `engine.setDebugOverlayVisible(false)`, usually in `Game.init`, and `engine.isDebugOverlayVisible()`
  - or `-Dengine.debugOverlay=false` on the command line

  Before this, the text always started visible and a game had to fake an `F3` press to hide it.

## Build
- The GitHub workflows use `actions/checkout@v7`, `actions/setup-java@v6` and `actions/upload-artifact@v7`, which run on Node 24. GitHub had flagged the old versions as deprecated.

## Use it

```xml
<dependency>
  <groupId>io.github.ad0bert</groupId>
  <artifactId>engine-named-scratch</artifactId>
  <version>0.8.1</version>
</dependency>
```

Nothing else changed from v0.8.0, so upgrading is just the version number.
